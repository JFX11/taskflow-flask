# Результаты локальной проверки

Дата: 11 октября 2026 года.

Среда: Linux, Python 3.12.3, Flask 3.1.3, pytest 9.1.1, Playwright 1.63.0. Браузерные тесты выполнены в установленном Google Chrome (Chromium). Скачивание отдельной сборки Chromium в этой среде прерывалось сетевыми ошибками; поэтому использован официальный параметр `--browser-channel chrome`. В GitHub Actions workflow устанавливает Chromium.

```bash
pytest --browser-channel chrome --cov=app --cov-report=term-missing \
  --cov-report=xml --junitxml=reports/results.xml
ruff check .
```

| Проверка | Результат |
| --- | --- |
| Модульные тесты | 15 passed |
| Интеграционные тесты | 29 passed |
| Системные тесты | 4 passed |
| Всего | **48 passed** |
| Покрытие Python-кода с ветвлениями | **100%** |
| Ruff | All checks passed |

Покрытие: `app/__init__.py`, `app/db.py`, `app/routes.py`, `app/validation.py` — 100% для каждого файла. Всего 111 исполняемых операторов и 16 ветвлений по отчёту coverage.

Десктопный и мобильный интерфейсы проверены, скриншоты включены в `docs/`. Для скриншотов использовалась отдельная временная база с демонстрационными данными.

Локально доступен только Python 3.12; матрица 3.11/3.12/3.13 проверяется в GitHub Actions. Docker не установлен, поэтому локальная сборка контейнера не выполнялась. Результаты удалённого CI/CD нужно смотреть во вкладке Actions репозитория.
